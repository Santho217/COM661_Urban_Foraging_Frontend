About This Project

Urban Foraging Explorer is a web application developed for COM661 Coursework 2.

The application uses Angular for the frontend, Flask for the backend API and MongoDB for database storage.

Users can browse, search and filter demonstration foraging records and view detailed information about individual plants.

All foraging locations are fictional. This application does not provide verified plant identification or harvesting guidance.
