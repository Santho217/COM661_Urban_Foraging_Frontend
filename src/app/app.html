About This Project

Urban Foraging Explorer is a student project developed for COM661 Coursework 2.

This website uses Angular for the frontend, Flask for the backend API, and MongoDB for storing and managing information.

The project helps users explore information about plant species and foraging locations. All demonstration locations are fictional and must not be used as real foraging guidance.
